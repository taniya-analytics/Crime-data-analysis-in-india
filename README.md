# Crime-data-analysis-in-india
●	Analysed a large-scale Indian crime dataset containing 33,000+ records to study crime patterns, trends, and outcomes 
●	Performed data cleaning and preprocessing by removing non-predictive columns, handling missing values, and encoding categorical variables 
●	Conducted exploratory data analysis (EDA) to examine crime distribution by city, crime domain, weapon used, victim demographics, and time 
●	Built classification models using Random Forest to predict case closure status (Yes/No) and evaluated performance using accuracy, precision, recall, F1-score, and confusion matrix 
●	Implemented XGBoost classification to predict crime domains (Fire Accident, Violent Crime, Traffic Fatality, Other Crime) with high predictive accuracy 
●	Applied feature importance analysis to identify key factors influencing crime outcomes, such as crime description, crime code, victim age, and police deployment 
●	Designed interactive Power BI dashboards with KPIs, trend analysis, crime distribution, case closure status, and weapon usage insights 
●	Generated data-driven insights to support understanding of crime hotspots, crime trends over time, and factors affecting case resolution
